# Fast Convert / 闪电转换

> 版本：v1.1.2  
> 面向 Windows 11 / 现代 PC 的轻量级视频批量处理工具。  
> 专注于 MP4 转码、二次压缩与流复制重封装，具备极简拖放体验、中英双语即时切换与实时进程资源监控。

## 快速开始

### 1. 安装依赖
双击运行：
```bat
install_deps.bat
```

### 2. 启动程序
双击运行：
```bat
start.bat
```
也可以在终端中直接运行：
```bat
python fast_convert.py
```

### 3. 打包单文件 EXE
运行打包脚本生成无外部 Python 依赖的单文件绿色版：
```bat
build_exe.bat
```
产物将输出在：
```text
dist\Fast Convert.exe
```

## 核心特性

- **三种工作模式**：
  - **转为 MP4**：自动扫描目录或已选的常见非 MP4 视频（RMVB、FLV、MKV、AVI、MOV、WMV、TS 等）并统一转码为高兼容度 H.264 MP4；
  - **压缩 MP4**：对已有 MP4 进行二次重编码压缩，可通过 CRF（16–32）与多档智能缩放（原尺寸、75%、50%、1080p、720p、480p）显著减小视频体积；
  - **重封 MP4**：纯流复制（Stream Copy）封装为 MP4 容器，不消耗 CPU 重编码，秒级完成封装修复。
- **三档转码速度梯度调节**：
  - 参数行提供「速度」下拉调节，精简为梯度明确的 3 档（避免多档“快”重复混淆）：
  - `快速 (推荐)`（`veryfast`，极高编码速度与兼顾画质）、`标准`（`fast`，均衡输出）、`高质量`（`medium`，更高画质与压缩率）。
- **拖放与智能目录记忆联动**：
  - 右侧交互区支持直接拖入单个视频、多选视频或文件夹，也支持点击手动浏览选文件；
  - **智能自动切换**：拖入或选择视频时，顶部工作目录自动切换为首个视频所在的目录，并自动持久化记录到配置文件；
  - **免拖拽续跑**：下次启动时自动加载上次记录的目录，若该目录下有待处理视频，无需重新拖拽，直接点击「开始转码」即可全自动扫描并处理。
- **多语言国际化 (i18n)**：
  - 首次启动自动根据操作系统语言选择中文或英文；
  - 顶部工作目录右侧设有地球图标（🌐）快捷入口，点击即可弹窗选择语言，全界面热重载瞬时刷新，无需重启。
- **左下角实时资源监控**：
  - 实时显示当前程序及 FFmpeg 转码子进程的总 CPU 占用（归一化系统占比）与工作集物理内存；
  - 鼠标悬停可弹出详细 Tooltip，展示主程序与子进程各自的 PID/CPU/内存明细以及系统整体资源概况。
- **底栏实时转码进度与剩余时间预估 (ETA)**：
  - 自动捕获 FFmpeg 输出并解析视频总时长、当前编码时间码与实时倍速（`speed`）；
  - 底栏中央动态展示预计剩余时间与单/多文件百分比（如 `预计剩余 04:25 (45%)` 或 `[2/3] 预计剩余 04:25 (45%)`）；
  - 鼠标悬停支持查看包含当前文件、已转码时长/总时长、当前速率等详细 Tooltip 指标。
- **开箱即用与自包含**：内置独立 FFmpeg 运行时，同时具备多候选路径与系统 PATH 自动降级探测能力。

## 文件清单

| 文件 / 目录 | 说明 |
|-------------|------|
| `fast_convert.py` | 应用程序核心主程序（PySide6 GUI + FFmpeg 异步多线程执行器） |
| `i18n.py` | 国际化语言包（系统语言嗅探、中英文词典、响应式信号） |
| `config.json` | 配置文件（版本号、端口、当前语言、上次工作目录、CRF等参数持久化） |
| `requirements.txt` | 运行依赖清单（PySide6, psutil） |
| `FastConvert.spec` | PyInstaller 单文件打包规范配置 |
| `start.bat` | Windows 启动脚本（处理 UTF-8 编码） |
| `install_deps.bat` | 依赖自动安装脚本（镜像源加速） |
| `build_exe.bat` | 单文件 EXE 一键打包脚本（打包后自动生成桌面快捷方式） |
| `create_shortcut.ps1` | 桌面快捷方式生成脚本 |
| `assets\` | 应用程序图标（.ico, .png）与矢量图标（globe.svg 等） |
| `resources\` | 内置 FFmpeg 二进制运行时 |
